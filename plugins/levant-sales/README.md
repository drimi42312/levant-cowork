# levant-sales

כלי שיווק ומכירות של לבנט (LVNT) עבור Claude Cowork.

## מה בפנים

- **presale-atrium** - הכנת מיילי פריסייל לפרויקט THE ATRIUM // שדרות ירושלים 94 ת"א
- **presale-hadoar** - הכנת מיילי פריסייל לפרויקט HA-DOAR // הדואר 8 יפו
- **crm-leads** - קליטת לידים ותיעוד פניות ב-Fireberry CRM
- **/presale-email** - פקודה מהירה להכנת מייל פריסייל

## דרישות (חד-פעמי, לכל משתמש)

1. Claude Desktop עם Cowork.
2. חיבור Gmail (connector) - הטיוטות נוצרות בחשבון של המשתמש.
3. חיבור Fireberry CRM (connector).
4. תוסף Claude in Chrome - לצירוף קבצים לטיוטות.
5. גישה לתיקיות ה-Dropbox המשותפות של הפרויקטים (LEVANT/פרויקטים/...).

## עקרון חשוב

הידע העסקי (טמפלטים, מחירונים, תוכניות, חוברות) חי בתיקיות ה-Dropbox של הפרויקטים ומתעדכן שם - לא בפלאגין. הפלאגין עוטף רק את תהליכי העבודה. הוראות העבודה המחייבות לכל פרויקט נמצאות בקובץ הטמפלט שבתיקיית השיווק שלו.

## הפרדה בין פרויקטים

כל סקיל מוגבל לתיקיית הפרויקט שלו בלבד. כשלא ברור באיזה פרויקט מדובר - קלוד ישאל ולא יניח.
